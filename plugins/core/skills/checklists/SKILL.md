# Workflow checklists

Five phase checklists, one file each, in this skill's directory. Read only the
file for the phase at hand: plan.md, review.md, test.md, security.md, handoff.md.
Check every item. These are judgment aids, not bureaucracy: in the reply, name
only the items you skipped, marked n/a or found blocked, each with a short reason.
Do not list the items that passed.
